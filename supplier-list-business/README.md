# Verified Supplier List Business: Starter Kit

This kit is everything you need to start selling **verified** supplier contact lists. It covers real factories only, never replicas.

> **Read this first.** The supplier names in `02-supplier-leads.csv` are **unverified leads** found through public web research. They are *not* yet a product. What you sell is the verification work: you check the company, talk to the supplier, order samples, and get their consent to be listed. Sell a list before that work is done and you become one more scam list, which is exactly what buyers already distrust.

## What's in here

| File | What it is |
|---|---|
| `01-business-plan.md` | Niche, offer, pricing, costs, 30-day launch plan |
| `02-supplier-leads.csv` | 15 starting leads (heavyweight streetwear / blanks + branding), status "unverified" |
| `02-supplier-tracker.xlsx` | Same leads in a tracker with an automatic 0–100 vetting score |
| `03-vetting-sop.md` | Step-by-step checks for each supplier before it goes in the list, plus the scoring rubric |
| `04-outreach-messages.md` | Copy-paste messages in English + Simplified Chinese (inquiry, consent to list, referral deal, follow-ups) |
| `05-product-template.md` | What the buyer actually receives, with a supplier profile card format |
| `06-legal-and-policies.md` | Disclaimer, terms of sale, refund policy, privacy/GDPR notes, rules for staying out of trouble |
| `07-marketing-plan.md` | Where to find buyers, content ideas, posting scripts |
| `sales-page/index.html` | Ready-to-edit sales page (open it in a browser) |
| `08-self-critique.md` | Weak points of this plan and how the kit addresses them |

## Order of work

1. Read `01-business-plan.md` (10 min).
2. Run every lead through `03-vetting-sop.md` and log it in the tracker (1–2 weeks).
3. Message suppliers with `04-outreach-messages.md`. Get prices, MOQs and **consent to be listed**.
4. Order samples from the top 3–5 (budget about €250–570).
5. Fill in `05-product-template.md` with only the suppliers that passed.
6. Edit `sales-page/index.html` (price, your name, payment link) and publish it.
7. Follow `07-marketing-plan.md`.

Nothing here is legal or financial advice. Check the rules where you live, especially tax registration for selling digital products.
